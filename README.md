# Millennium Dream Collage

这是一个可以发布到 GitHub 的 Codex Skill。用户上传一张照片并用一句简短的话调用它后，Skill 会把照片视为素材来源，选择一个视觉主角，并将其他素材重新组织成一个完整、怪诞、空间关系不正常的拼贴画面。

## 第一版重点

- 不保留原照片的完整构图和背景。
- 每张图只有一个明确的视觉主角，由1～2个占主导地位的主素材构成；较小的同类回声属于次素材。
- 每一种次素材最多出现4个，数量是上限而不是配额。
- 次素材可以陪衬、对抗、打断、连接或形成局部小场景，不必全部指向主素材。
- 所有重要素材都要参与某种视觉关系，不能成为孤立陈列品。
- 最终画面要组成一个可以被描述的新整体，而且第一眼就能感觉到空间秩序被打破。
- 重复、倒置、拉伸、旋转、散落和变形都是可选工具，不是必做任务。
- 怪诞感来自空间重组和对原始秩序的破坏，不来自撕纸、牛皮纸或全局滤镜。
- 规整、对称或重复的原图必须主动打破至少一种原始规律。
- 画面不能被同一种素材铺成连续大片，需要保留呼吸空间，但不能把整体挤到角落并留下大片死区。
- 默认让综合视觉重心保持在画面中部；偏心构图必须由次素材重新取得平衡。
- 必须同时看见一种局部干净拼接边界和一种素材关系变化，但不能给所有元素统一描边或切成面板。
- 建筑和场景平面可以使用白线、矩形或倾斜裁切；树木等有机素材优先保持自然轮廓、遮挡和组合生长。
- 如果选择拆分主体，必须同时改变错位、大小、角度、深度或重新连接中的至少两项，不能只加一条白缝。

像素化、反色、鸽子、叶子、阳光、老手机、文字和复杂旧式界面暂不默认加入。

## 使用示例

上传一张图片并输入：

`使用 $millennium-dream-collage 拆解并重组这张照片，生成一个整体成立但空间关系怪诞的拼贴画面。`
